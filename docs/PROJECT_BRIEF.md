# reBot RS 屏幕桌宠需求基线

当前以用户指定的《reBot RS 桌宠开发资料包》为准，完整提取正文见 [原文](reference/development_spec.txt)，原始参数见 [JSON](../config/behavior_defaults.json)，实现对照见 [REFERENCE_IMPLEMENTATION.md](REFERENCE_IMPLEMENTATION.md)。

目标是在现有 ESP32-C5 工程上增量实现触摸驱动的桌宠：固定底座的身体序列帧、独立眼睛、探头/轻蹭/歪头/退缩/安抚恢复/开心/休息/唤醒。开心来自有效抚摸，不设置情绪播放按钮；状态与播放分离，停止即时冻结。

第一阶段仅屏幕与动作意图 Mock，两路 CAN 待机。复用当前外设初始化、显示与触摸映射。采用指定原图，不重新设计角色，不从图像猜测电机关节角度。

先完成行为及资源流程，再用同角色同视角的精修帧和实机测试完善表现。交付源码、参数、资源工具与清单、构建产物、操作文档及真实验证记录。当前不新增编舞、记忆挑战或硬件功能。此前自拟生命感方案已被本资料包替代。
