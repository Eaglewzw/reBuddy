# 基于 ESP32-C5 的 reBot RS 机械臂桌宠方案书

## 一、项目目标

利用现有 ESP32-C5、屏幕和机械臂控制硬件，开发一款通过屏幕触摸互动、通过机械臂动作表达情绪的桌宠。突出角色的可爱形象、互动可玩性和实体动作表现，形成可现场体验与视频展示的作品。

计划周期为一个月。

## 二、核心功能

| 功能 | 内容 |
| --- | --- |
| 屏幕角色 | 保留 reBot 的黄绿色配色、多关节及夹爪特征，呈现待机、开心、好奇、困倦等表情动画 |
| 触摸互动 | 支持点击、抚摸、快速划动和连续点击，触发不同回应 |
| 表情与身体联动 | 屏幕表情与机械臂动作协调，支持平滑切换与回位 |
| 两种行为风格 | 支持“活泼”和“慵懒”，通过动作速度、幅度和停顿体现差异 |
| 待机与休息 | 无操作时逐渐进入困倦与休息状态，触摸后唤醒 |

可选扩展为动作编舞：通过屏幕排列已有动作、选择节奏并播放，在核心功能完成后酌情增加。

## 三、动作设计

| 动作 | 机械臂表现 | 触发方式 |
| --- | --- | --- |
| 探头看你 | 缓慢前伸、轻微侧倾，停顿后回正 | 点击角色 |
| 舒服地蹭蹭 | 末端轻微倾斜、小幅左右摆动，配合放松表情 | 缓慢抚摸 |
| 害羞缩回去 | 末端后撤、肘部收拢，配合害羞表情 | 连续点击 |
| 开心小舞蹈 | 身体抬起、左右摆动，夹爪轻轻开合 | 点击“开心”按钮 |
| 歪头不理解 | 末端向两侧轻微倾斜，配合疑惑表情 | 快速来回划动 |
| 打瞌睡 | 缓慢低头、短暂抬头，再收拢休息 | 无操作达到设定时间 |

动作采用低速、小幅运动，具体姿态通过实机调试确定。“蹭蹭”表现为屏幕互动触发的拟人动作，无需机械臂接触用户。

## 四、实现方式

ESP32-C5 负责界面显示、触摸处理、行为状态管理和动作调度，复用现有机械臂控制接口执行动作。

采用预设关键姿态、平滑插值和表情时间轴实现互动。两种行为风格共用动作库，通过参数调整呈现差异。处理连续触摸、动作中断与异常停止，保证交互响应和运行稳定性。

## 五、交付与验收

交付可体验的桌宠 Demo、源码与固件、动画资源、动作配置、简要运行说明及展示视频。

验收重点：

- 五类核心功能和六个动作可正常使用。
- 触摸反馈明确，表情与动作协调，两种风格有可辨识差异。
- 休息与唤醒流程完整，动作切换平滑，停止操作有效。
- 完成连续 30 分钟互动测试，无程序崩溃或明显卡死。
