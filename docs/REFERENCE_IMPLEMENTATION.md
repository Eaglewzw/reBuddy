## 素材与阶段限制

原始 PNG 原样保存在 `assets/reference/`：

- `character_reference.png` SHA256：`b42a5e1ee9da828628e7b29dae52c21bbc282a3349eebe447b3ea4dbf332fd1c`
- `interaction_storyboard.png` SHA256：`05d224aff1004a584e093d7e25842a05f21213aaa2006b0d7e0fffa75eab664a`

角色图作为实际像素来源，互动图作为动作含义参考。没有重新生成角色。当前使用统一待机角色做有限二维变形，不将不同格子的静态图直接连续播放。原图脸部已清理，底座下部在所有帧保持一致。

`assets/animation/manifest.json` 保存帧偏移、像素校验值、眼睛锚点、角度、动作/起点、相位时间、循环、结束姿态及切换点。每个动画有 11 个时间节点，稳定/停留帧会重复；**尚未满足每段 8～12 张不同关节姿态的成品目标**。收拢/展开/夹爪仅有原型变形，后续需同角色同视角的精修序列。歪头与轻蹭根据本次横向位移选择方向，反向片段同样在离线阶段生成。原型通过稳定起点衔接，不支持任意姿态直接连接。

RGB565 每帧为 LVGL 9.5 的 12 字节头 + 51,200 字节像素，使用小端。背景为不透明 `#f8f7ef`，与角色画布一致。`colorbars.bin` 提供红绿蓝白黑色条供字节序及实屏颜色核对，未替代实机色条验收。

## 静态预算与运行信息

| 项目 | 当前值/状态 |
| --- | --- |
| Flash 配置 | 8 MiB、DIO、80MHz |
| 应用分区 | factory，偏移 `0x10000`，大小 `0x7f0000`（8,323,072 字节）；无双 OTA |
| 身体资源 | 74 张去重帧、17 个片段，3,789,688 字节（约 3.61 MiB） |
| DMA | 内部 DMA RAM，2×320×40×2 = 51,200 字节 |
| 帧缓存 | PSRAM，两张 160×160 RGB565 = 102,400 字节；按需复制 |
| PSRAM | 板卡配置 8 MiB、Quad 40MHz；启动输出实际大小、free/min/largest，尚无本版实测 |
| 行为模型 | C5 ELF 中静态 `rb_pet_t` 9,752 字节（内部 BSS）；核心无堆分配 |
| 固件 | 4,301,232 字节（约4.10 MiB），应用分区剩余4,021,840字节（48.3%）；保留既有LVGL PSRAM分配策略 |
| 升级方式 | 既有串口烧录，分区未改变；未添加 OTA |

身体目标 15FPS 是选帧上限；11 节点及停留导致部分动作每秒实际换图数低于 15。20ms 是 UI/触摸调度周期，不能当成全屏帧率。每 5 秒 `rb_animation` 记录身体换图次数和输入到 UI 处理耗时，`rb_display` 记录绘制/提交，每 30 秒 `rb_memory` 记录堆；它们都不能单独证明触摸到面板首个光学反馈延迟。
