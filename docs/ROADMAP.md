# 一个月开发计划

项目起点为 2026-10-21，按四周安排，核心功能优先。具体联调日期随设备可用情况调整。

| 周次 | 工作 | 周末可检查结果 |
| --- | --- | --- |
| 第 1 周 | 建立 ESP32-C5 工程；复用屏幕/触摸；角色原型；手势、状态机、两种风格；运行屏幕 Demo | 可编译固件和实屏触摸；六个动作的屏幕预览；停止与睡醒流程 |
| 第 2 周 | 复用 RS 反馈与控制；标定中性姿态和上下限；先联调探头、蹭蹭；建立真实停止和错误恢复 | 两个低速实体动作；新鲜反馈、控制超时、停止和重新启用流程实测 |
| 第 3 周 | 调整六个动作和夹爪；表情与反馈到位联动；打断/回位；休息姿态和唤醒；两种风格实机对比 | 五类功能和六个动作完整演示；连续触摸不会堆积指令；风格差异可辨 |
| 第 4 周 | 完成连续 30 分钟真机测试与修复；整理固件、资源和配置；录制展示视频 | 完整验收记录、演示视频、源码与固件包、运行说明；剩余时间再做动作编舞 |

当前已完成第一周的软件起步部分和主机验证，上板测试仍待进行。后续不能以模拟运行结果替代实机验收。

## 动作编舞（可选）

核心验收全部通过后再增加。初步范围：最多 8 段，屏幕选择动作、调整顺序、选择速度档并播放。继续复用现有动作库、停止锁存和异常处理；播放中不接受无界队列，也不放宽实机限位。

## 展示视频脚本

1. 展示实体与屏幕角色、点击探头。
2. 慢抚摸蹭蹭、连击害羞、快速来回划动疑惑。
3. 开心小舞蹈，展示夹爪小幅开合。
4. 同一动作的活泼 / 慵懒对比。
5. 困倦、休息、触摸唤醒。
6. 运动中停止、释放急停与手动恢复。

成片应展示真实设备。当前预览截图仅记录界面，尚无实体演示视频。
