# 硬件与参考版本

本项目自带 `rebuddy_board` 板级组件，针对 XIAO ESP32-C5 CAN Console 的接线实现显示、触摸和按键支持。以下是当前硬件配置，尚需实机复核；构建不依赖其他应用仓库。

| 项目 | 配置 |
| --- | --- |
| 开发板 | XIAO ESP32-C5 CAN Console |
| 显示屏 | ST7789；原生 240×320，横屏 320×240；RGB565；SPI 默认 40 MHz，可配置回 20 MHz |
| 触摸 | GT911，I²C 地址 0x5D |
| 扩展器 | PCA9535；LCD、触摸复位、背光、实体输入和 CAN 待机控制共用 |
| Flash / PSRAM | 8 MiB / 8 MiB Quad 40 MHz，当前板卡配置 |
| 机械臂 | reBot RS；ID1–3 RS06、ID4–7 RS00；前六轴为机械臂，J7 为夹爪 |
| CAN | 两路；当前收发器 STB 拉高待机，未启动 CAN 控制器 |

| 信号 | GPIO / 扩展器 |
| --- | --- |
| LCD SCLK / MOSI / CS / D-C | 8 / 10 / 7 / 25 |
| I²C SDA / SCL | 23 / 24 |
| GT911 INT / RESET | GPIO0 / PCA9535 P0.1 |
| LCD RESET / 背光 | PCA9535 P0.0 / P0.5 |
| 波轮 A / B / PUSH | PCA9535 P0.2 / P0.3 / P0.4 |
| ENTER / BACK | PCA9535 P0.6 / P0.7 |
| PCA9535 INT | GPIO9 |
| 急停 | GPIO28，低有效 |
| CAN1 TX / RX | GPIO5 / GPIO3 |
| CAN2 TX / RX | GPIO2 / GPIO4 |

横屏触摸变换为 `(x, y) = (raw_y, 239 - raw_x)`；不要在桌宠 UI 再次旋转触摸坐标。字符和截图使用逻辑 RGB565，RGB565 使用 ST7789 小端 RAM 模式，LVGL 不重复交换字节。

初始化顺序为急停输入、共享 I²C、PCA9535、ST7789、GT911、LVGL、按键任务，随后创建桌宠 UI。PCA9535 地址为 `0x21`，输出锁存器先写入、再切换方向；P1.0/P1.1 始终保持 CAN 待机，P1.2–P1.4 高电平关闭状态灯。GT911 地址为 `0x5D`，初始化时将 INT 拉低选择地址，再恢复输入。

按键任务每 10ms 轮询 PCA9535，普通按键消抖 20ms，BACK 无消抖延迟。触摸每 20ms 轮询；I²C 事务超时为 20ms。触摸读取失败会取消当前触摸，避免生成误点击；按键读取失败会锁存软件停止。板级启动失败会报错并中止本次启动，不静默运行残缺界面。日志通过 USB Serial/JTAG 输出，每 30 秒打印内存状态。

当前 PSRAM 缺失会按当前板卡配置中止启动。更换无 PSRAM 板卡时应独立修改配置并重新测量内存；不能沿用此固件直接声称适配。

## 首次上板检查

1. 确认 Flash / PSRAM 容量和电源；先测试屏幕互动版本。
2. 检查显示朝向、角色点击、四角触摸及实体按键。
3. 验证 GPIO28 按下后显示 STOPPED，释放后仍需手动清除。
4. 记录 30 分钟的内部堆、PSRAM 堆、最低剩余与最大连续块。
5. 完成动作适配与标定后另行验证机械臂；当前软件急停只控制本 Demo，未宣称能够切断电机电源。

## 显示刷新配置

当前使用 20ms 刷新目标与两块 320×40 RGB565 DMA 缓冲（内部内存共 51,200 字节），角色预先缩放和编码。串口每 5 秒输出绘制/提交统计；具体指标、主机对比和 40MHz 上板检查见 [DISPLAY_PERFORMANCE.md](DISPLAY_PERFORMANCE.md)。
