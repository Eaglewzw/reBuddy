# 验收记录

主机模拟、图片检查和编译状态见 [验证摘要](verification/current.json)。当前资源为关键姿态预览；动画视觉、触摸手感及 30 分钟实机运行需要在开发板上验收。

记录模板：

- 日期、板卡、操作者、固件 SHA256、SDK 和配置版本。
- Flash / PSRAM 检测值、内部与外部内存最低余量。
- 显示朝向、颜色、触摸坐标和头部触摸范围。
- 轻点、身体抚摸、摸头开心、快划、三击收拢及安抚展开。
- 活泼／慵懒差异，持续睡眠、呼吸／Z、长按左下角唤醒。
- 暂停／继续、右下设置、触摸中断后重新操作。
- 连续运行起止时间，是否满 30 分钟，卡顿、重启与内存变化。
- 日志、演示视频、问题复现步骤及结论。

当前不验收实体按键、电机动作或编舞。
