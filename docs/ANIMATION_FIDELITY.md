# 动画视觉标准

以 `assets/reference/` 中的角色设定和互动分镜为依据，保留黄绿色连杆、银色圆盖、黑色夹爪以及发光眼睛、眉弧和腮红。固定相机、角色比例和底座位置，关节应表现旋转而非橡胶拉伸。

探头应有伸展与回位，轻蹭体现侧靠，收拢体现连杆折叠，安抚从收拢逐步展开，开心配合上身抬起和夹爪动作。睡眠保持折低姿态，身体持续呼吸，Z 从大到小上浮淡出；唤醒从实际睡姿展开。

每段动作需要足够的不同姿态与自然衔接。通过编译、主机测试或导出多个文件不能证明动画达到视觉验收标准。当前 28 帧为关键姿态预览，仍需补齐中间帧及改善局部结构一致性。
