## 目标关键姿态

| 动作 | 必须符合的画面 | 动画结构 |
| --- | --- | --- |
| 待机 | 主角色完整关节、银色圆盖、黄绿色连杆、黑色夹爪，原图眼形及腮红 | 轻眨眼、微小关注；身体保持已对齐的中性姿态 |
| 轻点探头 | 示意01：上段向触点伸出，肘部打开，夹爪随腕部前伸，睁大眼关注 | 待机→伸展前探→停留观察→关节依次回位 |
| 抚摸蹭蹭 | 示意02：头部侧靠、上段随之弯曲，弯眼笑，轻柔摆动 | 进入侧靠→左右轻蹭→自然回位 |
| 连续戳缩回 | 示意03：腕部及连杆向内折，夹爪收到脸前，紧张目光 | 惊讶→折叠退缩→保持；不继续逐级缩小 |
| 安抚靠近 | 示意04：从收拢逐渐打开肘部，头部重新靠近，眼神恢复明亮 | 放松→展开→靠近轻蹭→待机 |
| 持续抚摸开心 | 示意05及角色图开心：连杆抬起、上身舒展、弯眼笑、夹爪张开 | 抬起→左右轻摆和夹爪开合一次→回位 |
| 好奇歪头 | 角色图好奇：明确的头部倾斜、朝向触点的眼神 | 注视→倾头→停留→回正；保持主角色关节结构 |
| 困倦/唤醒 | 示意06：连杆整体折低，头部靠近基座，闭眼，夹爪放低 | 眼皮下垂→折低→闭眼停稳；唤醒从同一睡姿逐步展开 |

固定相机和基座，不改变角色比例，不让金属圆盖在弯曲过程中变成橡胶。原图身体、面部和夹爪需要协同。每段制作8～12张不同姿态的连续帧并逐帧检查，不能用文件数量替代姿态质量。

## 视觉验收顺序

1. 对照原图检查关键姿态：轮廓、关节结构、眼形、材质、夹爪及情绪。
2. 对照每段连续帧检查：固定底座、比例一致、关节连续、无残影/拉伸/跳变。
3. 播放探头、退缩、开心、困倦四个最明显的动作，检查轮廓差异和节奏。
4. 通过视觉检查后再接回现有行为状态机，测真实屏幕效果及性能。

不把旧原型的18项主机测试结果用作新动画视觉验收，也不在素材尚未完成时声称动画已经还原。
