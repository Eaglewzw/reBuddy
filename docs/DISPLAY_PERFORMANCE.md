# 当前显示策略与测量口径

资料包版本使用160×160不透明RGB565身体帧，Flash存储、PSRAM缓存两帧，眼睛独立。背景静态，优先局部刷新。身体选帧目标15FPS，使用约67ms累进截止时间；动画迟到按时间推进，不积压补画。关键姿态停留、11时间节点及慢风格会使实际换图次数低于15/s。

保持SPI40MHz、两块320×40 RGB565内部DMA缓冲（总51,200字节）、UI与输入20ms调度。20ms不代表50FPS。SPI单线40MHz理论5MB/s，320×240整屏约30.7ms，未含命令、绘制及调度开销。

不变文字/样式不重复设置；身体帧编号不变不换图。主机UI测试检查相同状态更新100次发送像素为零，以及反复操作无持续堆增长。

## 串口统计

- `rb_animation body_changes`：每秒更换身体图片次数，不等于面板完整显示帧率。
- `feedback_to_ui`：原始按下到模型确认且UI处理的耗时，不含触摸芯片之前的采样或面板最后传输延迟。
- `rb_display redraw`：渲染并提交次数；静止时低是正常现象。
- `render_submit`：绘制到最后一块提交的平均耗时，包含中间等待，不含末块DMA全部完成时间。
- `pixels/redraw` / `queued`：像素量与RGB565提交速率，不含命令。
- `rb_memory`：每30秒内部/PSRAM空闲、历史最低、最大连续块；启动打印PSRAM实际大小。

当前未采集本版实机日志，不能宣称达成15FPS或触摸延迟指标。上板应先确认色条、坐标和PSRAM，然后覆盖持续抚摸、动作衔接、睡醒与停止，记录日志及可见反馈视频。40MHz如不稳定可在menuconfig降低频率。
