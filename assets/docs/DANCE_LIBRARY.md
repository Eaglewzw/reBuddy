# 基础舞蹈库

当前仅保留一套动作，目录为 `record/dance_library/`。它由最后确认的精选 v8 整理而来，
保存 12 份独立轨迹，不再依赖旧基础库、showcase 或精选版本目录。

```bash
cd /home/verser/esp32/reBuddy/tools
./dance --supported
```

输入 `01`～`10` 逐组播放，完成后保持位置。`00` 开场、`11` 收尾。
`stop` / Ctrl+C 制动保持；`quit` 回零退出。故障后的保持与恢复方式沿用原控制器。
旧命令中的 `--selected` 仍可用，指向同一套动作；已移除 showcase 分库入口。

## 夹爪与验证范围

02、06 的 J7 每轮 2 秒：1 秒打开到 90°、1 秒闭合，没有顶点停留。
仅这两组使用 J7 快拍限值 2.8 rad/s、10 rad/s²，实际峰值约 154.56°/秒、540°/秒²。
1.5 N·m 力矩限值、KP/KD、10.8° 跟随窗口、闭合到位判定和故障保持保留。
40/60 ms 跟随延迟模拟中 J7 估算力矩峰值约 0.625/0.900 N·m；这是离线结果，尚未实机验收。

模型手指仅标定闭合状态；02/06 的自碰撞检查使用闭合手指代理，不代表活动手指完整碰撞验证。
环境未自动建模。10 的固定点是工具 +X 前方 20 cm 的虚拟点，模型精度不等于实体指尖精度。
软件保持依赖供电和通信，现有防坠支撑要求保留。

## 数据与工具

`manifest.json` 固定动作编号、名称、时长、校验和、标定身份和 Daily 首尾来源。
加载时检查当前模型、完整轨迹及动作语义。编号与固件动作 ID 分开；当前尚未集成 Flash 或同步屏幕 GIF。
旧原始录制已清理，当前库不依赖 `record/dance/`。录制/处理入口仍保留，后续录制会自动创建该目录。

代码按职责划分为 `rs_dance_library.py`（加载）、`rs_dance_motion.py`/`rs_dance_plan.py`（轨迹）、
`rs_dance_console.py`（执行）、`rs_dance_nod.py`/`rs_dance_cute.py`/`rs_dance_steady.py`（当前编排）
及定点运动学辅助模块。旧动作数据、旧库生成入口及相应历史预览已移除。
