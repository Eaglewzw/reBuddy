# 编舞编辑与屏幕预览

从小屋右下角“设置 → 编排”进入独立编辑页。编舞只使用用户选定的十组舞蹈，日常触摸动作不出现在动作库，也不会作为过渡自动插入。实体机械臂联动尚未接入，“同步表演”保持禁用。

## 动作库

| 动作 | 标准时长 |
| --- | --- |
| 点头打拍 | 2.4 秒 |
| 抬臂舒展 | 2.4 秒 |
| 深蹲回升 | 2.4 秒 |
| 前探伸展 | 2.4 秒 |
| 底盘回转 | 2.4 秒 |
| 大幅摇摆 | 2.4 秒 |
| 折肘展开 | 2.4 秒 |
| 抬头俯看 | 2.4 秒 |
| 夹爪开合 | 2.4 秒 |
| 大幅波浪 | 2.4 秒 |

“我的编排”、动作库及作品内步骤列表均支持手指上下滑动；右侧滚动条表示位置，页面提示总数与“上下滑动查看”。可从卡片、卡片间隙或右侧空白区域开始拖动，滑动不会选中或添加动作。顶部与底部操作区保持固定。

每个作品最多 8 步，最多保存 10 个作品。每个动作可重复 1–3 次，重复不额外占用步骤。选中步骤后可前移、后移或删除；新增动作插入选中项之后。

“停留”是保持当前画面的计时积木，不是额外动作。可设置 0.5–3 秒并占一步；开头的停留显示第一个舞蹈的起始画面。每个舞蹈结束后还可设置 0–3 秒停留，两者均以 0.5 秒调整。

## 背景与节奏

播放时复用现有小屋 `assets/images/source/room/room.png` 对应的 `room.bin`。显示层把舞蹈画面中与边界相连的浅色底替换为小屋；机器人内部的眼睛与金属高光保持原样。原始 GIF 和解码基准帧均不改写，角色尺寸、动作轨迹和播放时长保持不变。

标准节奏基本动作每段 2.4 秒，开场收尾各 3 秒；高帧率舞蹈在板端按 10 FPS 取帧，底盘回转保留每帧 150 ms。慢节奏为 1.5 倍时长，快节奏为 0.8 倍时长；动作与停留统一变速，画面比例不变。这些是屏幕动画时长，实体机械臂速度及姿态仍需标定。

预览顶部显示当前动作与进度，下方保留停止操作。停止或播放结束后保持当前帧；点击重播才从头开始，不自动循环整段作品。不同舞蹈按源素材直接衔接，不补入日常动作。每次从头播放或重播时，自动执行 3 秒开场、用户编排、3 秒收尾；空作品不可播放，开场收尾不占步骤，结束后保持收尾末帧。停止和故障停止不会跳转执行收尾。自动段也随慢／标准／快节奏变速，总时长已包含自动段。

## 保存与恢复

十个作品槽位使用 NVS 双记录、序号与 CRC 校验。保存时写入较旧记录；写入失败或中断时保留原有效记录。打开、加载与重启均不会自动播放。未保存退出时可保存、放弃修改或继续编辑。

新舞蹈使用 ID 33–42，停留使用 ID 15；43/44 仅用于自动开场收尾，禁止作为手动步骤保存。日常动作 ID 与旧舞蹈 ID 不允许用于编排；旧作品包含这些动作时会提示无法读取，需要明确确认重建并保存，不自动替换或覆盖原内容。加载和保存均执行相同的动作范围校验。

## 日常界面与硬件边界

进入编排后暂停日常动画、触摸手势与无操作计时，退出后恢复进入时的日常状态；原本休息的桌宠继续休息。编排不会影响 Daily GIF 资源，也不发送电机命令。

屏幕停止、故障停止、动作时序和背景合成有主机测试；真实刷新率、内存峰值与连续 30 分钟运行仍需实机验收。接入机械臂时还需验证限位、碰撞、轨迹和停止链路。
