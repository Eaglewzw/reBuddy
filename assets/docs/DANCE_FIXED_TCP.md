# 10：大幅定点左右上下

当前基础舞蹈库中的 10，沿用整理前最后确认的连续轨迹。

```bash
cd /home/verser/esp32/reBuddy/tools
./dance 10 --supported
```

P 相对原待机虚拟点下移 12 cm，位于约 `[0.523910,-0.006694,0.288603]` m；
虚拟点是 `gripper_end` 沿工具 +X 前移 20 cm。准备朝向下倾 10°，左右 ±20°、上下 ±18°。
默认倍率 1.0，总时长 16.74 秒；进入和返回阶段 P 随过渡移动，舞段内保持固定。

左右回收和上下起步在约 7.79～11.19 秒重叠衔接，原回中处保持运动。
边界位置、速度、加速度连续，方向极值处自然减速换向。模型固定点误差要求小于 2 mm，
仍检查关节、奇异度、模型自碰撞和动力学；环境未建模，实体精度需实测。

数据：`record/dance_library/10_pivot.json`。实现：`rs_dance_pivot_sway.py`、
`rs_dance_pivot_join.py` 及共享 IK/运动学模块。完整菜单见[基础舞蹈库](DANCE_LIBRARY.md)。
