# 动画视觉标准

舞蹈首先以 `assets/gifs/daily/01_待机眨眼.gif` 的外观、身体厚度与关节尺寸为基准，再参考 `assets/images/reference/` 中的角色设定和互动分镜，保留黄绿色连杆、银色圆盖、黑色夹爪以及发光眼睛、眉弧和腮红。固定相机、角色比例和底座位置，关节应表现旋转而非橡胶拉伸。

夹爪结构统一为左侧、右侧两个完整单元。每侧自身不可再拆成两个夹指、分叉小手或额外关节；单侧运动必须保持完整轮廓和固定尺寸，绕安装点整体转动或随身体移动。当前十个基本舞蹈按 B601-RS 的单一夹爪开合自由度设计，左右两侧联动，不作为独立手臂挥动。单独保留的 V6 捂鼻／扇动预览是历史屏幕表现，不作为实体机械臂能力依据。后续原画、分层及逐帧验收均遵循此规则；自动测试不能代替对画面结构的检查。

抬头应先注意目光，再小幅抬头、停留注视与回位，避免伸展感，轻蹭体现侧靠，收拢体现连杆折叠，安抚从收拢逐步展开，开心由摸爪触发，从待机起身到肩肘舒展，同一夹爪的两个爪指同步张合两次后回位。入睡先两次慢眨眼，中间短暂睁眼撑住，再眼皮变沉、低头闭眼、安静睡下；正常状态入睡不经过睁眼害羞收拢姿态。睡眠保持折低姿态，身体持续呼吸，Z 固定字号上浮淡出；唤醒从实际睡姿展开。

每段动作需要足够的不同姿态与自然衔接。通过编译、主机测试或导出多个文件不能证明动画达到视觉验收标准。当前 GIF 以平均 8 FPS 播放关键姿态，仍需补齐中间帧及改善局部结构一致性。

已选定的 probe-v2 原图与两帧 GIF 作为重要参考保留，但不代表已完成连续帧或集成进固件。详情见 [素材状态](../README.md)。

当前十个舞蹈由完整角色姿态图集导出，以 daily 外形为参考，按整图连通轮廓提取完整角色，避免格子边界裁断头部和夹爪。每张图集统一固定采样，只平移定位；不再采用部件分层拼接。原画的局部轮廓和刚体尺寸仍需视觉确认，源图与筛选时间轴见 [舞蹈源文件](../images/source/dance/individual/README.md)。
