# 动画视觉标准

修改日常动画时，以当前 Daily GIF 本身为角色母版。头壳轮廓、身体厚度、三个关节的位置关系、夹爪大小、发光眼睛画法和像素质感均须延续原版，不能用重新生成的另一种机器人外形替代。原始角色参考用于核对，不作为重新设计当前角色的理由。固定相机、角色比例和底座位置，不采用缩放或拉伸制造动作。

当前 WITHDRAW 与 RECOVER 使用 GitHub main 分支的原版 GIF，缩回 3 秒、展开 5 秒。表情试做稿保存在工程外，不作为正式运行资源。后续修改须以原版完整姿态和外形为基准，先单独审阅，再决定是否替换。

夹爪结构统一为左侧、右侧两个完整单元。每侧自身不可再拆成两个夹指、分叉小手或额外关节；单侧运动必须保持完整轮廓和固定尺寸，绕安装点整体转动或随身体移动。后续机械臂动作按 B601-RS 的单一夹爪开合自由度设计，左右两侧联动。后续完整角色逐帧原画及验收均遵循此规则，不采用拆分部件拼接制作动作；自动测试不能代替对画面结构的检查。

抬头应先注意目光，再小幅抬头、停留注视与回位，避免伸展感，轻蹭体现侧靠，收拢体现连杆折叠，安抚从收拢逐步展开，开心由摸爪触发，从待机起身到肩肘舒展，同一夹爪的两个爪指同步张合两次后回位。入睡先两次慢眨眼，中间短暂睁眼撑住，再眼皮变沉、低头闭眼、安静睡下；正常状态入睡不经过睁眼害羞收拢姿态。睡眠保持折低姿态，身体持续呼吸，Z 固定字号上浮淡出；唤醒从实际睡姿展开。

每段动作需要足够的不同姿态与自然衔接。通过编译、主机测试或导出多个文件不能证明动画达到视觉验收标准。当前 GIF 以平均 8 FPS 播放关键姿态，仍需补齐中间帧及改善局部结构一致性。
