# 项目目标与范围

在 ESP32-C5 和现有屏幕硬件上制作 reBot RS 桌宠：角色住在小屋中，通过触摸与预设关键姿态互动。交付源码、配置、动画资源、固件和运行说明，目标包括可现场体验及视频展示。

当前实现轻点探头、抚摸轻蹭、快划歪头、三击收拢、安抚展开、摸爪开心、持续睡眠及长按唤醒；两种风格共用资源。仅使用触摸屏；独立编舞页支持十组舞蹈动作与停留、每段最多 8 步、10 个保存槽位、节奏选择和屏幕预览。十组选定舞蹈支持屏幕编排，实体电机控制尚未接入。

原始资料包正文保留在 [资料包正文](reference/development_spec.txt)，其中硬件按键、独立眼睛、普通触摸唤醒及“不新增编舞”等条目已由后续交互要求替代。当前行为以 [开发指南](GETTING_STARTED.md)、[编舞说明](CHOREOGRAPHY.md)、`assets/config/behavior_defaults.json` 和运行代码为准，视觉设计参考 [动画视觉标准](ANIMATION_FIDELITY.md)。

## 后续开发

1. 在开发板确认纯触摸流程、手爪区域和抚摸速度容差，记录误触及丢触情况。
2. 细化关键姿态之间的连续帧，保持关节形状、连杆长度和底座一致。
3. 改善连续跟眼、入睡／唤醒与动作中断的视觉衔接。
4. 在标准 B601-RS 模型及实机上验证十个基本舞蹈的可达性、限位、碰撞、速度与精度，并据此细化姿态衔接与节奏；补充待机自主张望与身体调整。
5. 确认机械臂协议、轨迹、姿态与停止链路，接入共同时间轴和实体后端。
6. 完成 30 分钟真实交互与编舞运行、显示性能与内存观察，录制展示视频。

编舞编辑与屏幕预览已接入，保存使用 NVS；当前没有 CAN 运动命令。实体同步表演、机械臂标定和协作臂适配仍属后续工作。屏幕预览仅连接十组选定舞蹈，节奏倍率和总时长不代表经过实机标定的机械臂运动能力。
