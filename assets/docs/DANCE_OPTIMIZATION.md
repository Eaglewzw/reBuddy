# 舞蹈播放、衔接与 Flash 预算

屏幕十组动作和当前 `record/dance_library` 对应。板端编舞仍为屏幕预览，尚未接入 Dance 的 CAN 同步执行；GIF 关节投影不能替代实机运动校验。

## 时序与衔接

- 采用渲染器实际逐帧时长，名义 12.5 FPS；最长 16.74 秒片段约 210 帧，帧表上限 256。GIF 可合并重复帧，RGBA 帧时间轴是固件的权威输入。
- 标准节奏保留实机轨迹时长；自动开场 5.5 秒、收尾 7 秒，不再一律压为 2.4 秒。十组时长见 [资源清单](../gifs/dance/README.md)。GIF 10 ms 时间单位引入的总时长误差不超过 5 ms。
- 各动作循环首尾一致。08 使用已确认的完整角色原画，单独记录端点组；其余九组及开场末帧、收尾首帧共享相同待机画面。资源生成器验证各组原始端点，不硬换帧；测试检查每个循环及同组跨动作连接。08 与其他动作的跨组切换仍有原画差异。
- 新轨迹已经平滑处理，播放不叠加旧的首尾相位缓动。慢速为 1.5 倍时长，快速为 0.8 倍时长；标准节奏保留原时间轴。
- 停留仍以 100 BPM 的半拍（300 ms）编辑，旧 500 ms 等值不改变原意；主动调整才对齐半拍。

## 透明度与存储

画面保持项目原角色，固件存储 160×160 原生索引平面，以预乘透明度双线性重建为 240×240，居中显示在原 320×240 房间中；不使用重复像素放大。RGBA PNG 连同轨迹及 SHA-256 入库，避免仅保存 GIF 的一位透明度而丢失抗锯齿边缘。

固件资源使用共享 32 色、8 级覆盖率，提前在电脑上编码。覆盖率来自渲染 alpha，先量化到 8 级，再以同一覆盖率合成白底并量化颜色；解码恢复预乘前景后双线性插值，避免透明边黑白光晕。封闭连杆空隙显示原墙面，白色高光和眼睛保留；不再依赖旧 `dance_cavity_seeds` 的源图或调色板哈希，也不走旧底盘回转专用插帧路径。Daily 像素和时序保留原编码过程。

Dance 使用新 codec 6/7 存储原生平面及有限深度索引/覆盖率 XOR 差分，最多七层。每八帧一个独立锚点，随机访问、跳帧、重播、损坏回退由 C 解码测试覆盖；解码器缓存已恢复平面。动画缓存峰值仍为 614,400 字节（600 KiB），不含 LVGL、DMA 或其他堆内存。扩大帧索引表仅增加静态元数据，不增加帧缓存数量；双线性解码另有 5,952 字节静态颜色/坐标查找区，避免占用 LVGL 任务栈。

资源 FPS 不等于实测屏幕 FPS。板端使用 `rb_decode` 和 `rb_display` 的解码/合成/显示统计确认连续播放表现，观察快速摇摆、8 字和定点动作。

## Flash 预算

[flash_budget.json](../config/flash_budget.json) 保持原约束：应用分区 8,323,072 字节，动画 blob 不超过 **5 MiB**，完整应用不超过 **6,225,920 字节**，至少留下 **2 MiB**：

| 用途 | 预留 |
| --- | ---: |
| 后续轨迹、姿态、机械臂参数 | 512 KiB |
| CAN、调度及其他代码增长 | 1 MiB |
| 未分配余量 | 512 KiB |

当前全 12 段 Dance 加 8 段 Daily 的 `frames.bin` 为 **4,628,420 字节**（约 4.41 MiB），距动画上限还剩 614,460 字节。此数不包括代码、字库和房间。本轮完整应用为 **5,649,280 字节**，分区剩余 2,673,792 字节；扣除必须保留的 2 MiB 后还有 576,640 字节。

生成器超出动画预算时不写正式产物；`idf.py build` 和打包检查完整应用。当前 Daily 实机数据与代码必须一并计入应用大小，不能只检查 GIF 压缩率。若超限，优先减少源帧采样或调色板开销，不能提高预算。预留不是独立分区，不移动 NVS，不清除已有作品。

## 旧作品与验证

新库使用 ID 45–54；33–42 永久退役，43/44 仍是自动开场/收尾。旧作品显示“旧版作品”，禁止静默替换动作含义；原 NVS 数据保留，确认重建并保存后才产生新版本。WAIT-only 旧作品仍可读取。

验证包括：RGBA 哈希与真实 alpha、GIF/轨迹时长和名称映射、每帧 CRC 与独立解码、共享首尾、节奏缩放与停止保持、旧作品拒绝及显式重建、所有十组触摸选择、Flash 超限测试。Daily 原图、RGB565 像素与时间轴另外逐帧校验。

实际 C 编排核心/资源解码器可生成样板：

```bash
build/host/rebuddy_dance_preview build/host/dance-preview.rgb565
ffmpeg -f rawvideo -pixel_format rgb565le -video_size 320x240 -framerate 20 \
  -i build/host/dance-preview.rgb565 -c:v libx264 -pix_fmt yuv420p build/host/dance-preview.mp4
```

输出视频使用 20 FPS 容器采样实际时间轴，不会凭空增加原 GIF 的运动姿态。上板仍需检查正常/快速节奏、停止重播、背景空隙、最低内存与连续运行；主机结果不替代设备验收。
