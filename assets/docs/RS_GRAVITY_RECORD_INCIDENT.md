## 用户确认的恢复目标（正常退出已接入，故障恢复未实现）

用户要求异常后回到“机械臂校零时的姿态”。当前标定下，J1～J6 的目标为原始电机角度 0 rad；J7 的标定零位对应夹爪闭合。标定文件中的微小 `positions_deg` 是校零后读数，不是另一个需要写入的零点偏移。回到该姿态是位置运动，不能通过重新写入电机零点来代替。该目标也不同于 `presets/idle.json` 的待机姿态。

后续恢复控制必须先区分故障：只有在全部关节反馈重新得到可靠确认、驱动及通信正常、当前位置到校零姿态的路径经过验证时，才可能执行受控回零。关节角度在限位内不等于路径已经通过碰撞和承重验证。回零属于主动运动，需要单独验证速度、加速度、力矩及到位后的保持策略；用户要求录制时不按拖动速度停机，不应被解释成回零可以无限速。夹爪闭合也须纳入路径和接触验证。

持续无效反馈、通信中断或断电时，不能保证自动回零。回到零位也不自动证明可以失能承重。目前没有将 `finally` 的失能调用替换为无条件零位命令。正常退出在进入清理之前调用 `move_to_zero_pose`，失败会明确记录后再失能到支撑；沿用参考函数的六轴归零与夹爪保持语义。此功能不代表软件已具备故障回零或独立防坠能力。
