# 睡眠表情局部修补

`pose-atlas-no-blush.png` 与 `breath-atlas-no-blush.png` 由 imagegen 在原姿态图和呼吸图上去除两侧粉红发光腮红，保留眼睛、眉毛、结构、姿态、尺度与网格布局。

固件不整张替换角色：`tools/neutral_sleep_assets.py` 按 [retouch.json](retouch.json) 的两侧脸颊边界识别原腮红及一像素边缘，只复制生成图中的局部黑色面屏修补像素。其他像素继续使用原图。生成图的 SHA-256 也记录在配置中。

- 正常待机、抬头、开心、害羞等共用的原帧 0–23 不变。
- 入睡专用帧 28–32 分别对应原帧 0、23、16、17、15，使用同样的手爪触摸区域。
- 熟睡呼吸帧 24–27 同步去除腮红，避免入睡后重新出现粉红发光。唤醒开头从实际无腮红睡姿开始，醒来后继续使用原表情。
- 动作时间轴、底座、呼吸与 Z 节奏保持不变。

生成要求：仅去除每格机器人脸部两侧的粉红/橙红发光短线及光晕，用周围一致的黑色面屏材质补齐；保持所有眼睛、眉毛、壳体、关节、夹爪、底座、姿态、尺度、照明、原始尺寸和网格位置；不添加五官，不重绘角色。
