# 舒展开的开心回应原画

内置 imagegen 根据 [角色基准](../interaction-v3-8fps/idle-master.png) 和 [互动示意图](../../reference/interaction_storyboard.png) 制作。完整生成提示词保存在 [prompt.txt](prompt.txt)，原画为 [atlas.png](atlas.png)。

峰值姿势通过肩肘关节展开，让中段连杆更直立，头部抬高、手爪向前上方伸出，保留三个独立可见的银色关节。第 8、10 格张爪，第 9、11 格收爪，形成两次轻开合。相机和底座固定，不加入缩放动态。

[timeline.json](timeline.json) 推荐 8 FPS、6 秒、48 个时间格。选帧采用前段逐步展开，爪开合后沿前段原路返回；不用第 2、3 格的先抬高再回落变化，也不用末排另画的回位帧，以减少跳变。首尾均使用第 0 格。

所选帧经视觉检查均有三个银色关节。生成原画的零件细节仍可能存在差异，不能视为机械轨迹或实机效果已验证。该目录不改变现有 GIF 或固件，由上层导出器接入。
