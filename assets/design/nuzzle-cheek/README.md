# 固定肩肘的脸侧轻蹭

本轮按用户反馈把动作集中到头部：肩、肘和主要连杆保持原姿态，笑眼的脸侧轻靠，短程擦过、稍退，再蹭一次，最后回正。角色保留三个银色关节和一只闭合双指夹爪。

使用内置 imagegen，参考 [角色基准](../interaction-v3-8fps/idle-master.png) 生成 [初稿](initial-atlas.png)，完整提示词为 [prompt.txt](prompt.txt)。初稿的肩肘稳定但头部动作几乎不可见，所以用 [refine-prompt.txt](refine-prompt.txt) 再次定向修正，形成 [最终图集](atlas.png)。图集为 4×4，但仅选用第一排四个姿态往返，减少原画差异。

[建议时间轴](timing-suggestion.json) 为 8 FPS、6 秒；在头侧贴近时有 750ms 停留，两次轻蹭使用相同四个源姿态，首尾同帧。

检查依据记录在 [joint-registration-analysis.json](joint-registration-analysis.json)。整张图集仅固定采样为 640×640 后，比较第一排四格的银色圆盘局部模板：肩、肘的最佳匹配位移全部为 `[0,0]`，没有以前连杆展开、关节整体升降的动作；腕部原画差异约横向 0–2px、纵向 0–1px。脸部两个笑眼的连线从约 21.75° 变为 27.34°，且脸侧沿短弧向下靠近，动作变化集中在头部。模板测量属于图像检查，不能推算机械臂真实角度；生成细节仍有轻微差异，未声称每个零件逐像素完全相同。

视觉检查四格都保持三个关节可见、同一视角、单个闭合夹爪。夹爪有随头的轻微位移，形状没有变成两只手。没有使用逐帧缩放、拉伸或合成旋转来纠正原画。
