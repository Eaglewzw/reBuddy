# screen-preview-v1 素材来源

- 角色身份参考：`assets/approved/idle_master.png`；造型沿用用户资料包的 reBot RS。
- 生成工具：内置 `image_gen.imagegen`，一次生成。
- [完整提示词](prompt.txt) · [原始 24 格姿态图](pose-atlas.png)。
- 用户要求先做一版烧录体验，因此该图已接入试烧固件；这不表示用户已通过视觉验收。

图集为 1536×1024、6 列×4 行。`tools/build_screen_preview.py` 负责逐格切分、统一缩小、仅外部背景归一化、整数像素落地对齐、共用底部接地边缘和 RGB565 编码。原图保留不改，不使用网格拉伸或插值造帧。运行资源中的 `source_sha256`、`registration`、`frames` 记录校验值、落点偏移和每帧来源名称。

当前有 24 张独立姿态，不是每段各 24 帧；多段动作共用姿态，停留和回程也会复用帧。局部结构及上部底座绘制仍有差异，歪头和收拢等动作的中间帧偏少，需结合实机反馈继续细化。眼睛烘焙在图内，播放器直接显示图内表情。
