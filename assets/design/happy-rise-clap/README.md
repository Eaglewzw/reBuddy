# 起身、舒展和单夹爪开合

最终 [atlas.png](atlas.png) 为同一张 4×4 图集，包含从待机起身到舒展笑眼、夹爪双指开合的连续姿态。完整动作只使用这一张图集，不跨来源切换角色尺寸。图集已冻结，SHA-256 为 `d8867e85fe9016585025f6419c650355b847552c60141c4c26eaf4aa5a4fa0ee`。

使用内置 imagegen。参考 [原角色](../interaction-v3-8fps/idle-master.png) 定义尺寸与造型，[上版夹爪动作](../happy-symmetric-clap/atlas.png) 仅用于双指开合方式。初始提示词见 [prompt.txt](prompt.txt)，起身中间姿态的定向修正见 [rise-correction-prompt.txt](rise-correction-prompt.txt)。

[timeline.json](timeline.json) 推荐 8 FPS、8 秒、64 拍。0–6 格起身，6/7/8 分别是舒展闭合、半开、张开。两次开合都复用这三格，再用 5–0 格逆序回位；首尾都是第 0 格。避免使用另外绘制的相似开合/回位帧。

采用姿态均可见三个银色关节。夹爪是同一个腕连接下的两个实体黑色爪指，半开和张开时两指都运动，没有任何一指被分成 V 形。起身中间角度步距仍不完全均匀，需要导出后按实际播放判断节奏。

源图为 1254×1254，每格约 313–314 像素。[source-review.png](source-review.png) 是采用姿态的原像素切片；[registered-check.png](registered-check.png) 是统一采样与底座位置对齐后的检查图。手工初检的像素量级如下，测量为轮廓目测约值、误差约 3 像素，旋转会改变轴对齐包围框，不应据此缩放原画：

| 部件 | 采用帧中的约值 | 初步判断 |
| --- | --- | --- |
| 头壳横向轮廓 | 157–166 px | 未见明显整体放大，存在细节差异 |
| 腕侧银帽直径 | 57–62 px | 约 5–10% 范围差异 |
| 近侧绿色指根宽度 | 42–44 px | 未见明显拉长 |
| 黑色近指长轴 | 40–45 px | 未见成倍增长，需独立复核远指和开合帧 |

独立审核已复核第 6–8 格：在 160 像素角色采样下，近侧黑指长轴目视约 20–23 像素，远侧张开时约 21–23 像素；闭合远指受到遮挡，不能直接将整体夹爪包围框的增宽视作单片变长。两指确实同步运动。仍可见第 7 格掌座轻微横向偏移、第 8 格远指绿色根部的细节变化。

这些检查不能证明各个零件几何严格相同。最终是否符合无放大观感，应结合夹爪与头壳比例、指根和单指长度以及整段播放效果判断。运行时不使用逐帧尺寸拟合来掩盖差异。

## 与其他动作的尺寸衔接

导出时整段 HAPPY 使用固定 `1.125` 倍的画面布局校准：原待机姿态的底座前板约 32 像素，待机与轻蹭约 36 像素。全部姿态使用相同比例、同一底座锚点，不随时间缩放；房间保持原尺寸。角色先放到完整房间画布上，起身后的头顶不会被原 160 像素角色框裁切。手爪触摸区域同步更新。此项统一动作之间的整体大小，不会消除原画本身的细节漂移。
