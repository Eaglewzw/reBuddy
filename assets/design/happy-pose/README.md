# 单夹爪舒展开的开心姿态

采用内置 imagegen，依据 [原角色](../interaction-v3-8fps/idle-master.png) 重新制作 [atlas.png](atlas.png)。完整提示词见 [prompt.txt](prompt.txt)。

这版取消夹爪开合和拍手，用肩肘舒展、抬头、笑眼表达开心。夹爪始终是同一个闭合部件，两指尖紧邻，共同通过一处腕连接向前上方举出。

[timeline.json](timeline.json) 只采用原画第 0、2、4、5、6 格。第 6 格的舒展笑眼姿态保持 2.25 秒（18 个 125 ms 时间格），然后沿原姿态温和回位。全段为 8 FPS、6 秒、48 格；首尾都使用第 0 格。取消前版两次开合，峰值不再更换原画，避免手爪形态变化造成分裂感。

采用的五个姿态已逐一检查：三个银色关节可见；夹爪两指相邻闭合、同一腕连接，无第二只手或独立夹爪。此目录仅保存原画与选帧方案，实际导出和实机效果由上层进一步核对。
