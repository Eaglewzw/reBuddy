# 单夹爪双指同步开合原画

最终候选为 [atlas.png](atlas.png)，**2×2 图集**：闭合、半开、张开、闭合。固定舒展肩肘笑眼姿态，只通过同一个夹爪的两指开合表达轻鼓掌。近侧爪指向左下张开，远侧爪指向右上张开；每根黑色爪指都是一整片，不再把其中一片拆成 V 形。

使用内置 imagegen。第一轮全动作图集未通过姿态与双指运动检查，未采用。第二轮聚焦少量关键帧，提示词见 [keyframes-prompt.txt](keyframes-prompt.txt)；第三轮加大近侧爪指的运动，提示词见 [symmetric-correction-prompt.txt](symmetric-correction-prompt.txt)。[keyframes.png](keyframes.png) 是第二轮来源；[open-pose-reference.png](open-pose-reference.png) 是从现有 happy-pose 第 6 格提取的参考。

[timeline.json](timeline.json) 给出固定姿态两次开合的 8 FPS、6.5 秒方案，只采用最终图集第 0、1、2 格，反向播放回合，保证使用同一组原画。第 3 格不参与循环。若与原有从待机展开/回位连接，应由主导出器将夹爪状态接入峰值并检查比例，不可忽略不同图集角色位置差异直接拼接。

逐格检查结果：三个银色关节均可见；两个黑色爪指均发生运动；没有一根黑色爪指变成 V 形双指，没有第二根腕杆。透视下两指屏幕位移不同，尚不能证明实际机械角度严格对称。供主流程继续做整体合成与实机视觉评估。

导出时整张图集统一采样到 320×320，再按 160×160 切为 4 格；不得套用 4×4 图集的 640×640 采样。
