# 完整角色与尺寸稳定性预览

[查看 GIF](02_固定比例律动_预览.gif)。这是 3 秒、平均 8 FPS 的单段方法验证，尚未接入固件，也不是十个舞蹈的完成稿。

每个姿态使用完整绘制的机器人，不裁切头部、肩肘或夹爪来驱动动作。已剔除图集中尺寸漂移明显的姿态，只采用 1、2、3 三个完整姿态往返两次，重拍停留。导出前以 daily 底座为刚性尺寸基准，对整张角色原画做离线尺度标定；三个有效姿态的底座宽度均为 93 像素，接地点为 (155,190)。播放时不再缩放或变形部件。

这段只验证外观稳定性与完整姿态衔接，动作幅度较小；底盘回转、完整舞蹈表现和其他九段仍需制作与审看。固定底座尺寸不能证明生成图的所有局部轮廓完全一致，不把程序检查视为视觉验收。
