# 十个基本舞蹈动作

**当前状态：新一轮十个独立动作，待视觉验收。此次先完成基本动作素材，尚未制作新的编舞组合，也未进行硬件验证。**

以 daily 中厚实的机械臂形象为参考，围绕标准 reBot Arm B601-RS 的基座回转、肩肘屈伸、腕部运动和夹爪开合设计。每段单独查看，先判断动作是否清楚、自然，再考虑编排。日常互动 GIF 保持不变。

表中描述是逐段验收的目标，不代表实机已达到相同动作表现。全部素材均无音频；本目录只保留十个独立 GIF，不生成连续组合总览。

每个 GIF 为 320×240、平均 8 FPS：交替使用 120/130 毫秒帧延迟，平均每帧 125 毫秒。80 BPM 时间基准下，4 拍为 3 秒、8 拍为 6 秒。每段源图包含 12 个完整角色关键姿态，时间轴筛选可用姿态并通过重复关键帧形成停留，导出为 24 或 48 个播放帧，并非 24 或 48 个不同姿态。

原画位于 `assets/images/source/dance/individual/`。每张图集使用统一固定的输出采样比例，底盘落点定位到 `(155, 190)`，仅平移完整角色进行定位；不分层拼接头部、连杆或夹爪，也不添加运动缩放。左右夹爪应各自保持完整单元，不拆成手指或额外小手。来源哈希、姿态登记和帧时序见 [manifest.json](manifest.json)。

完整角色原画由图像生成制作，局部尺寸、透视和关节衔接仍需逐段视觉确认。固定采样和落点可以控制制作过程中的缩放与漂移，但不能证明原画每个部件严格等大，或保证刚体运动精度。

3／6 秒是屏幕设计时长与后续轨迹验证的起点，并非实机测量结果。真实关节角度、速度、加速度、碰撞、到位误差和停止过程仍需结合机械臂模型及实机验证；不能从屏幕像素直接换算电机命令。本版不发送 CAN 运动命令。

既有编舞编辑和内置示例功能继续保留，本次未新增组合舞蹈作品；GIF 更新也不等于已重新生成并验证固件。旧舞蹈、`cat-demo` 和“左右交替”不会因重新生成资源恢复。[V6 预览](../cat-v6/README.md) 单独保留，未接入固件。
