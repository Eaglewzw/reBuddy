所有原图为 640×640，十组基本动作每段 2.4 秒，开场和收尾各 3 秒。文件逐字节保留，SHA-256 记录在 manifest.json。

运行版本仍固定适配为 240×240、居中显示在小屋中。九个高帧率动作按 50 ms 取样，首尾覆盖源片段端点；底盘回转保留原始转身姿态并加入中立首尾连接。十组动作使用同一中立首尾，重复及跨动作连接可逐像素校验。

原 GIF 不改动，固件舞蹈另做共享 64 色转换、16 级轮廓覆盖率预计算和有限深度差分压缩，以提高时间分辨率并为机械臂预留空间。底盘回转的真实运动姿态数量仍有限，不能把 20 FPS 的时间轴等同于 20 个不同姿态／秒。

每次播放自动加入开场与收尾，不占 8 个手动步骤。标准 100 BPM，主体、开场、收尾各四拍（2.4 秒）；开场收尾的原始 GIF 仍各 3 秒。实体轨迹尚未标定。详见 [编舞](../../docs/CHOREOGRAPHY.md) 与 [优化及预算](../../docs/DANCE_OPTIMIZATION.md)。
