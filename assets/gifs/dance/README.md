[活力律动完整 Demo](00_活力律动_24秒.gif)：底盘转拍两轮 → 侧摆重拍两轮 → 上下律动两轮 → 左右交替两轮 → 连环波浪 → 舒展收拍，总时长 24 秒，可在编排界面继续编辑。独立“猫步律动”入口连续播放六轮共 12 秒，不占用保存槽位。当前均为无音频的屏幕演示。

2–4 秒单段是为后续机械臂配合预留的初步视觉节奏，不是实机运动耗时的测量结果；具体角度、限速和加速度确定后再同步调整。

源图与生成要求见 [初版设计素材](../../images/source/dance/basic/README.md) 和 [新增舞蹈素材](../../images/source/dance/extended/README.md)，时序、源文件哈希与定位数据见 [manifest.json](manifest.json)。新动作采用关键姿态切换，底盘为三个离散方向，仍需实屏评估衔接流畅度。

猫步采用六个摆动角度，每个停留 250–375 毫秒，末尾回到起始角度。参考原动作“一只手捂鼻子、另一只手动”：一侧夹爪始终贴住双眼下方的面部中央，仅另一侧绕自身铰点运动，不轮换固定侧、不做双指同步开合。底座、身体、头部和捂鼻侧使用同一固定图层，无动态缩放。源图和关节参数见 [猫步图层](../../images/source/dance/basic/cat-hand-v3/README.md)。

另有正在评估的 [V6 向上扇动预览](../cat-v6/README.md)：左侧捂鼻、右侧朝脸旁上方快速挥动，配合加速底盘转向；该预览尚未替换上述固件猫步素材。
