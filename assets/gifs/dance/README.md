所有原图为 640×640，十组基本动作每段 2.4 秒，开场和收尾各 3 秒。文件逐字节保留，SHA-256 记录在 manifest.json。

固件将完整画面固定适配为 240×240，居中放入 320×240 画布，资源转换时两侧使用源图角落背景色，不裁切角色、不动态缩放、不重绘。为适配 8 MiB Flash，九个高帧率动作按 100 ms 取样（10 FPS、24 帧）；底盘回转保留 16 帧、每帧 150 ms。动作总时长保持 2.4 秒。

播放界面使用现有小屋背景：显示层处理与画面边界相连的浅色底，保留角色内部高光及原始解码数据；不另存一份带背景动画，不增加一套 Flash 动画资源。

编排仅允许这十组舞蹈动作，可重复 1–3 次、调整顺序和节奏。舞蹈仅用于屏幕预览；触摸区域不用于舞蹈交互，机械臂姿态、限位及同步控制仍需后续实机适配。旧舞蹈 ID 保留为无效编号，不会把旧作品误解释成新动作。

每次播放自动加入开场与收尾，不出现在手动动作库，不占 8 个编排步骤；重复动作只重复主体，停止时保持当前画面，不强制执行收尾。

经用户确认，板端舞蹈（含开场、收尾）统一采用共享的 256 色色板，不使用抖动。色板由十二个源 GIF 的首、中、末帧生成并记录在运行清单中；颜色渐变可能略有差异，尺寸、帧率和时长不变，原始 GIF 文件不减色。
