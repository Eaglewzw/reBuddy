# 动作 GIF

这里保存当前小屋版的 10 个独立动作 GIF，便于逐个查看。角色姿态、动作节奏和疑惑问号来自与固件相同的资源与配置；问号和 Z 使用桌面字体近似 LVGL，GIF 不包含触摸按钮，也不是固件直接播放的文件。默认按实机「活泼」风格导出，动作时长包含全局放慢倍率；末尾额外停留仅用于预览。校验值和时长见 [manifest.json](manifest.json)。

| 文件 | 内容 |
| --- | --- |
| 01_待机眨眼.gif | 待机与眨眼 |
| 02_抬头看你.gif | 使用 GitHub 原版动作：注意、轻探头、停留注视、回位 |
| 03_轻蹭.gif | 单次向一侧轻蹭、短停留、回位；实机随触摸方向选择左右 |
| 04_疑惑歪头.gif | 先歪头，再让头顶三个大小错落的问号依次出现、微微上浮 |
| 05_害羞缩回.gif | 收拢 |
| 06_安抚展开.gif | 从收拢展开 |
| 07_开心回应.gif | 恢复原版开心造型，抬高手爪，张合两次表现鼓掌，再放回 |
| 08_慢慢入睡.gif | 两次慢眨眼，中间短暂睁眼撑住；眼皮变沉、低头闭眼，最后安静睡下，全程无腮红 |
| 09_熟睡呼吸与Z.gif | 无腮红睡眠表情、呼吸起伏、Z 从大到小上浮 |
| 10_迷糊唤醒.gif | 从睡眠展开 |

单向动作结尾跳回起始姿态只用于重复预览，实际交互不会自动跳回。抬头使用 GitHub 原版关键姿态和时序，保留内部空隙透出墙面的修正；开心回应使用原版素材调整举爪开合节奏，其余动作保留原有关键姿态；图像生成的细节一致性及实机触摸衔接仍需体验评估。

安装 Pillow 后运行 `python3 tools/export_action_gifs.py` 可生成到 `build/action-gifs/`；用 `--output` 指定新的空目录，用 `--style lazy` 导出慵懒风格。工具不覆盖已评估 GIF，也不修改固件资源。
