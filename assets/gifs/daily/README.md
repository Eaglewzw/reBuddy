# 灵动可爱 · 8 FPS 当前动画

本文件夹保存固件当前使用的 10 个独立 GIF，是运行动画的源文件。旧版 `assets/gifs` 已移除。固件构建使用由这些 GIF 转换的 RGB565 资源，保留相同帧内容与时间轴。

新版采用清楚的表情停留与动作节奏。角色不使用整图缩放、镜头推拉、弹性拉伸或形变补帧。入睡与熟睡没有腮红；开心从待机逐步起身、肩肘舒展，同一夹爪的两个爪指同步开合两次，再回位；疑惑时三个问号分次出现。Z 保持固定字号，仅上浮淡出。

## 机械臂时间如何估算

先假设一个小幅关节段的角行程为 Δθ、规划速度为 v、加速度为 a，使用从静止开始、到静止结束的梯形速度模型：

- Δθ ≤ v²/a 时，时间约为 `2 × sqrt(Δθ/a)`。
- 其他情况，时间约为 `Δθ/v + v/a`。
- 多关节同时运动取最慢关节的时间；前探、停留、回位等先后段再相加。
- 另加眼神准备、停留注视、夹爪开合和最终停稳的时间。

例如，抬头往返暂用两个 12° 的假设段，v=12°/s、a=40°/s²，运动预算约 2.6 秒，再留约 2.4 秒给关注、注视与停稳，得到 5 秒。插画里的头部仰角不等于机械臂关节指令。入睡暂用 28°、8°/s、20°/s² 的假设段，运动预算约 3.9 秒，加困倦和睡稳停留约 3.1 秒，得到 7 秒。

这些角行程只用于推算时间，不代表实际关节姿态，也没有从图片像素换算角度。当前没有负载、关节限位、控制器速度与加速度标定。后续应先实测每段可执行轨迹，再调整时间轴；电机应使用连续轨迹，不能每 125 ms 跳一次目标角度。

开心回应的 8 秒包含完整起身、舒展、两次夹爪开合与回位，全部使用同一图集。两次开合复用同一组闭合/半开/张开原画，回位逆序复用起身原画，避免跨来源切换造成比例跳变。原画的零件尺寸仍有细小差异，具体像素初检和限制见 [制作说明](../../images/source/daily/happy/README.md)。

## 本版制作与验证

使用内置 imagegen，依据 [角色基准](../../images/reference/approved/idle_master.png) 和 [互动示意](../../images/reference/interaction_storyboard.png) 制作独立动作原画。完整提示词、素材与选帧说明见 [制作目录](../../images/source/daily/base/README.md)。

导出只对整张图集做一次固定分辨率采样，再按底座标志做整数位置对齐。没有逐帧放大缩小、图像旋转拼接、网格变形、叠化或整体弹跳。轻蹭采用固定肩肘的新原画，仅选 4 个头侧轻靠姿态做两次短程往返；所选原画的肩肘局部模板最佳匹配位移均为 0 像素，详见 [原画检查](../../images/source/daily/nuzzle/joint-registration-analysis.json)。这项检查用于排除明显伸臂，不等于证明所有像素或零件几何完全相同。

10 个 GIF 的帧内容、帧延迟和总时长用于生成固件资源；运行时按触摸状态选择动作，单次动作结束后的状态由行为逻辑控制。活泼与慵懒暂时均以 1.0 倍时长播放，不额外加速或减速。生成原画的零件细节及不同动作之间的连接还需视觉和实机评估；程序未使用缩放不等于已验证每个零件的几何完全一致。当前不发送机械臂指令，构建和硬件验证状态见 [验证摘要](../../verification/current.json)。

重新导出：`python3 tools/export_gifs_v2.py`。结果写入本文件夹，再转换固件资源并重新编译才能更新设备。机器可读校验和实际帧延迟见 [manifest.json](manifest.json)。

待机眨眼使用完整黑色面屏内部蒙版合成，避免矩形裁剪留下睁眼残影；外壳与身体固定。回归检查：`python3 tests/host/gifs_v2_test.py`，覆盖闭眼残留、身体固定和全部新版 GIF 的时长与帧延迟。

连杆之间的封闭空隙按 [逐姿态种子配置](../../config/preview_cavity_seeds.json) 去除原画米白底色，显示同一位置的小屋墙面。种子绑定源图校验值，避免替换原画后误用旧坐标；回归检查会解码最终 GIF，并对照空隙位置与房间背景的颜色。

另有 [三关节表情预览](../expressions/README.md)：待机、开心、好奇分别保存为三个独立 GIF，各 4 秒、8 FPS。肩部、肘部、头侧的三个银色关节在所选原画中均清楚可见。

开心回应已统一与待机、轻蹭的整体尺寸：所有帧使用同一个固定布局比例，底座位置不动，播放过程中不改变比例。首尾底座前板与待机的解码像素边界偏差不超过 2 像素；起身的头部保留完整显示，摸爪区域同步对齐。

熟睡动画的 Z 使用 28 像素加粗字形，深橄榄绿色；飘起过程中保持清晰，最后 0.9 秒淡出。睡眠呼吸、6 秒循环和平均 8 FPS 时序不变。
