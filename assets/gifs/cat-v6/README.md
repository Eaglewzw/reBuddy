# 左侧捂鼻、右侧快挥

这是用户选定保留的 V6 版本，也是当前目录唯一保留的猫步候选 GIF。源图、绑定参数与导出工具一并保留，可以重新生成相同动画。

[查看新版 GIF](01_左夹指捂鼻_右夹指快挥.gif)

使用原夹爪的左右两侧：画面左侧的夹指抬到面部中央并保持捂鼻，右侧夹指快速向脸旁上方挥动，表现驱散气味；底盘同步原地左右转向。右侧运动范围从近水平到上举，不向下甩动。

左右两侧各是一个不可再拆分的完整夹爪单元；右侧整体绕安装点挥动，不将单侧拆成两个夹指或小手。后续修改同样遵循这条结构约束。

当前文件为夹爪结构修正版：右侧的黄绿色外壳和黑色爪面一体挥动，尺寸按左侧捂鼻夹爪校准。保留 8 FPS、2 秒循环和快速底盘转向；视觉效果待确认。

- 320 × 240，16 帧，2 秒循环，平均 8 FPS；帧间隔交替为 120 / 130 毫秒。
- 右侧夹指每 0.5 秒往复一次，底盘每 1 秒左右往复一次，均为上一版对应周期的四分之一。
- 固定镜头与部件比例，不增加手掌、手臂或动态缩放。
- 底盘仍采用三个离散方向，转向有跳变；这是屏幕动作预览，不是已标定的电机轨迹。
