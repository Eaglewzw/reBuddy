# 图片与设计源文件

PNG、SVG 等图片集中在这里，按制作、参考、展示三个用途管理。

| 目录 | 内容 |
| --- | --- |
| [source](source/README.md) | 日常动作、舞蹈、V6、房间及共用图层；原画与提示词、参数同目录 |
| [reference](reference/README.md) | 用户角色原图、互动示意和已选原画 |
| [previews](previews/README.md) | 当前界面截图、编舞截图、触摸区域示意 |

可播放动画统一位于 [gifs](../gifs/README.md)。源图仅编辑和导出时使用，固件直接读取 `assets/animation/` 的生成资源。
