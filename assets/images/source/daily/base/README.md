# 灵动可爱新版素材

这是当前 GIF 动画的设计源素材，输出位于 [日常 GIF](../../../../gifs/daily/README.md)。固件使用当前 GIF 转换的 RGB565 帧，不在设备上裁切原画图集。

使用内置 imagegen 工具，参考 [批准的角色基准](../../../reference/approved/idle_master.png) 和 [互动图](../../../reference/interaction_storyboard.png)，分别生成每个动作的 4×4 原画图集。实际图集尺寸、SHA-256 和固定采样比例由 [导出清单](../../../../gifs/daily/manifest.json) 记录，以当前源图实际分辨率为准。

| 原画 | 用途 |
| --- | --- |
| probe-look-up-atlas.png | 头部围绕上方关节仰起、面屏朝上注视，再回位；选取 0、4、5、6、7、8 格并反向返回，排除前段近似整体上移的 2、3 格 |
| [固定肩肘轻蹭原画](../nuzzle/atlas.png) | 只采用第一排 4 个姿态，肩肘保持位置，笑眼头侧短程往返两次 |
| [清楚侧歪原画](../tilt/atlas.png) | 固定肩肘，头壳和面屏一起侧滚，峰值停留 1.25 秒再回正；2×2 图集、三个有效姿态 |
| withdraw-atlas.png | 收拢，选定第 12 格为终态，排除后段闭眼似睡姿态 |
| recover-atlas.png | 从收拢展开，选用连续展开姿态 |
| [完整起身开心原画](../happy/atlas.png) | 同一图集逐步起身、完全舒展、双指轻开合两次，再沿原姿态回位 |
| rest-atlas.png | 无腮红困倦入睡；唤醒选用同一姿态序列反向展开 |
| idle-atlas.png | 按完整黑色面屏内部蒙版合成眨眼，保留相同外壳与身体像素；不用会截断右眼的矩形裁剪 |
| breath-atlas.png | 无腮红熟睡微动，选取前半程并原路返回 |

`idle-master.png` 是保留的角色生成参考；运行图集和时间轴以上表及清单为准。

[timing.json](timing.json) 保存每个动作的选帧、每姿态停留拍数、总时长、循环方式和机械臂时间预算假设。8 FPS 是显示时间基准，停留段会保持同一姿态；图片帧不直接转换为电机角度。

导出工具为 `tools/export_gifs_v2.py`。调色板在整段动画内固定，背景沿用现有小屋。连杆空隙使用 [逐姿态背景种子](../../../../config/preview_cavity_seeds.json) 去掉源图底色，并绑定源图校验值；更换原画后必须重新核对。孤立装饰线被排除。只做固定采样和底座位置对齐，不使用逐帧缩放来伪造动作。

当前 GIF 已作为固件动画源。原画细节的一致性、连接过渡和实机运动同步尚不能视为已验收。
