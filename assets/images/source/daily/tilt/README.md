# 清楚侧歪的疑惑姿态

当前可用图集是 [atlas.png](atlas.png)，为 **2×2**，不是4×4。三个有效原画按顺序为 [中立](middle.png)、[轻侧歪](moderate.png)、[明显侧歪](strong-peak.png)；第四格复用中立。三张都是1254×1254，用原尺寸无缩放拼为2508×2508；导出时整图一次采样320×320，每格160×160。

使用内置 imagegen 制作。单张编辑依次使用 [middle-prompt.txt](middle-prompt.txt)、[moderate-prompt.txt](moderate-prompt.txt)、[peak-prompt.txt](peak-prompt.txt)。角色原始参考为 [三关节角色](../base/idle-master.png)，歪头方向参考 [角色图](../../../reference/character_reference.png) 的“好奇”小图。当前保留这三张独立原画、最终图集及对应提示词，未采用的整图试稿已删除。

三个姿态的面屏与头壳共同向图像逆时针方向侧滚，眼睛连线由约-3.01°、-16.10°到-36.02°，右眼逐渐高于左眼。强峰值比最初15–22°目标更明显，完整眼轴变化约33°；轻侧歪图是幅度较小的候选。未使用缩放放大、整体角色倾斜或抬肩伸臂来制造动作。

[图像检查](pose-analysis.json) 记录对相同160px采样角色的关节局部模板比较：肩、肘、腕最佳匹配位移在三张中均为 `[0,0]`。这些测量只说明画面中主关节没有整体移动，不能据此导出真实机械臂角度，也不宣称每个生成细节逐像素完全一样。视觉检查三张均有三个银色关节、同一侧视角和单一闭合两指夹爪，连接完整。

[建议时间轴](timing-suggestion.json)：8 FPS、5秒，中立→轻侧歪→明显侧歪停留1.25秒→原路回正。问号由上层导出器添加。这里是三张原画的关键姿态预览，8 FPS表示播放时钟，停留段重复原姿态。
