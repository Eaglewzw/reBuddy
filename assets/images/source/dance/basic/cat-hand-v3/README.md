# 猫步：一手捂鼻，另一手摆动

动作参考 `assets/gifs/reference/月薪猫.gif`。原动作一只手始终捂着鼻子，另一只手单独运动；此版用 reBot 同一夹爪的两个夹指表达，固定侧不交换。

[图层源图](layers.png) 由内置 ImageGen 生成，[提示词](prompt.txt) 保存在本目录。左半张是固定角色，夹指贴住双眼下方的面部中央；右半张是另一侧的独立夹指。底座、身体、头部与捂鼻侧不参与运动。

[关节参数](rig.json) 指定夹指裁切范围、匹配铰点尺寸的固定比例、旋转中心及六个角度。夹指从近水平逐渐抬起、回落，再接回起始姿态。2 秒一轮，8 FPS，关键角度保持 250–375 毫秒。每帧只旋转独立夹指，不放大、不缩小，也不把整只夹爪移动到另一侧。

[实际合成姿态](poses.png) 和 历史 GIF（已删除，不再导出） 使用房间背景。自动检查覆盖：捂鼻区域与底座像素一致、活动区域之外不变、六个不同摆动姿态及循环首尾一致。GIF 调色时固定源像素复用首帧色索引，避免量化缓存导致固定区域颜色轻微跳动。

当前为屏幕表现，未映射到实体夹爪的独立驱动能力。

本目录仅保留历史源素材，不参与当前舞蹈导出或固件构建。
