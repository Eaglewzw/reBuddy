# 历史表演动作源素材

本目录仅保留旧原画与制作来源，不再由当前舞蹈导出工具读取，不生成旧舞蹈或猫步 Demo。当前十个基本舞蹈统一使用 [primitives](../primitives/README.md)。

保留 reBot 的荧光黄外壳、黑色屏幕、三关节和双指夹爪。素材由内置 ImageGen 生成，生成要求保存在本目录的 `*-prompt.txt`、`prompt.txt` 和 `claw-correction.txt` 中。`cat-hand-v3/layers.png` 参考用户提供的 `assets/gifs/reference/月薪猫.gif` 的一手捂鼻、另一手摆动，角色仍是 reBot。

`nod-pose-atlas.png` 使用第 0、1、2、3、12、14 格（从零计数）；第 13 格存在越界，未采用。摇摆和夹爪使用各自图集的第 0–2 格；摇头／鞠躬使用 `extra-atlas.png` 六格；猫步使用固定角色与独立夹指两个图层，生成要求及铰点参数见 [单侧手势说明](cat-hand-v3/README.md)。

旧导出流程对每张图集使用固定采样比例，以底座面板定位；传统图集逐姿态仅平移；猫步仅旋转独立夹指。不做动态缩放、形变或镜头推进。透明区域直接叠加原房间背景。猫步的底座、身体、头部和捂鼻侧使用同一固定层，只有另一侧夹指围绕固定铰点旋转；`palette.png` 锁定共用调色板，单独修改猫步不改变其余舞蹈的色彩。未采用的旧猫步图集已清理；`cat-hand-v3` 仅作历史素材保留，不再导出或用于固件，V6 选定预览另行保存。生成图的细小结构仍有差异，需用户在实屏确认动作观感。

[注册后的姿态检查图](registered-review.png) 展示实际房间合成效果；当前 [GIF 文件夹](../../../../gifs/dance/README.md) 已全部替换为新的十个基本舞蹈，不再包含本目录旧成品。这些历史动作是屏幕原型，尚未映射机械臂关节角度或经过电机速度验证。
