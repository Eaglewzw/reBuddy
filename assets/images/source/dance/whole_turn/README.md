# 08 完整角色多视角原画

使用内置 **image_gen** 绘制完整角色，包含底盘、肩部、两段连杆、肘部、头部和夹爪。九张原画从左侧经过正面转向右侧，各部位共同绘制；没有把独立头部贴到另一个身体上。

- `turnaround.png`：最终九宫格透明图集。
- `prompt.txt`：第一次完整角色绘图提示词。
- `directions_prompt.txt`：纠正九宫格观看方向的提示词。
- `cleanup_prompt.txt`：清理背景并统一眼睛画法的提示词。
- `views/00.png`～`08.png`：完整角色切片，整体注册到底盘中心 `(282, 540)`，保留完整绘图。
- `views.json`：原图校验值、切片缩放与平移参数。
- `registered_views.png`：九张完整原画的检查图。
- `inbetweens.png`：内置 image_gen 补绘的四张完整角色过渡原画，对应10°、30°、50°、70°。
- `inbetweens_prompt.txt`：本次补绘使用的完整提示词。
- `inbetween_views/`、`inbetweens.json`：过渡原画切片、整体注册参数与校验值。
- `inbetweens_registered.png`：四张过渡原画检查图。

参考输入为原 `build/dance-original/neutral-original.png` 与旧GitHub转身的九视角示意图。旧素材来源见上一级 `github_turn_reference.json`，本图集不是旧GIF的逐像素复制。

运行 `python3 -B tools/prepare_dance_whole_turn.py` 注册图集，再运行 `PYTHONNOUSERSITE=1 OPENBLAS_NUM_THREADS=1 /usr/bin/python3 -B tools/render_dance_whole_turn.py` 制作动画。绘图对应点通过保形三次插值形成中间姿态，整幅完整原画共用一个二维变换。相邻完整原画先通过共同对应点变形到当前姿态，再以双向光流对齐剩余线条差异，使用五次曲线连续融合，消除原先在视角中点直接换图的跳变。头部和身体共用整幅图的变形和融合进度。光流修正限制为12像素；这里只改变动画绘制，不修改机械臂轨迹。

08保留原输入的两轮摇摆相位和8.74秒时长，使用图集中正面至右侧的相应视角；头部、身体随完整角色一起转动，不再套用旧头部的独立屏幕坐标。角色绘图不是实机运动学仿真。09及实机动作数据不改。

本次仅优化08过渡：在原有姿态插值曲线上加入四张完整角色原画，使参与动画的视角间隔从20°缩至10°。新增绘图沿用原来的整体姿态对应点，头部和身体一起变换；不改变摇摆相位或时长。上面的准备命令会同时重建原图集和四张过渡切片。自动检查见 `assets/verification/dance_whole_turn.json`，包括首尾一致、底盘中心、动作时长和09文件未变化。

输出为 `build/dance-3d/whole_turn/`，对照页为 `build/dance-whole-turn/index.html`，主入口仍为 `build/dance-original/index.html`。当前仅更新电脑端预览，未加入固件Flash。

正面附近的运动最低约5°，没有越过正面。此段沿用10°完整原画并按原姿态曲线连续变形，不再切入肘部完全被遮住的0°原画，避免肘部突然出现或消失。渲染使用系统 OpenCV / NumPy；`PYTHONNOUSERSITE=1` 避免用户目录 NumPy 2 与系统 OpenCV 的 ABI 冲突。

肩关节尺寸稳定：下部关节使用第06张完整原画中的同一份肩关节纹理，排除不同视角纹理融合和残差光流缩放。垂直采样保持恒等；水平投影保持外壳左右边界194/346像素，金属端盖宽度随角度连续变化。夹爪遮挡仍使用当前帧，底盘下部使用固定原画像素。上部头身继续使用共同姿态插值；这是二维外观适配，不是机械运动学模型。

校验以实际RGBA输出为准：逐帧检查肩关节中线轮廓宽度、底盘像素一致性和循环首尾，而不只验证定位点半径。渲染参数见输出 `manifest.json` 的 `shoulder_geometry`。

连杆接合：上部姿态图中的肩轴与下部投影统一为 `(194 + cap_horizontal_radius, 381)`。连杆末端指向该轴后方18像素的连接点。肩壳合成时只在连接通道内保留其后面的连杆，不再用横向替换边界切断它；夹爪继续位于前景。逐帧检查肘部到肩轴的狭窄通道内前景连通性，同时保留外壳宽度和底盘像素一致性检查。
