# 基于 daily 外观的舞蹈绑定

> 历史分层原型：本方案已停止用于当前舞蹈导出。当前源文件见 [individual](../individual/README.md)。

十个舞蹈共用 daily 风格的粗壮连杆、大银色关节和完整双侧夹爪。外观校准基准为 [daily 待机 GIF](../../../../gifs/daily/01_待机眨眼.gif)，原图和播放时长不改动。

| 文件 | 用途 |
| --- | --- |
| [身体三视图](../../shared/gripper/body-flush.png) | 保留原有厚实身体和脸部，提供左／中／右三档转向画面 |
| [完整双侧夹爪](../../shared/gripper/jaws-solid.png) | 每侧黄绿色外壳与黑色爪面为完整刚性单元 |
| [身体生成要求](../../shared/gripper/body-flush-prompt.txt)、[夹爪生成要求](../../shared/gripper/jaws-solid-prompt.txt) | 已有原画由内置 ImageGen 制作；当前绑定直接复用这些素材 |
| `rig.json` | daily 尺寸基准、固定采样比例、三视图转轴与夹爪安装关系 |
| `motion.json` | 十个动作的底盘、肩、肘、腕俯仰、腕旋转及夹爪开口时间轴 |

身体固定使用 156/724 的源图采样比例，单侧夹爪固定使用 0.073，完整单侧约 32×32 像素。底座接地中心为屏幕 (155,190)。每个视图的连杆轴距从原图直接计算，动画内不变；视图之间的投影轴距不同，不通过拉伸图层制造转向。身体部件以原生蒙版绑定，保留完整下游银色关节遮盖连接处，只保留与当前部件相连的像素，排除裁切落入的悬浮碎片。

底盘转向使用三档已有原画姿态，接地不移动、上部与面板随转向变化；这仍是离散视角表现。肩肘采用更清楚的屈伸范围。腕俯仰改变头部朝向，夹爪组件可绕共同安装中心旋转；两个完整爪侧等量反向开合，不作为独立手臂挥动。每段回到共同的中性姿态。

动作以 80 BPM、平均 8 FPS 表现，4 拍 3 秒或 8 拍 6 秒，帧延迟交替 120／130 毫秒。十个独立 GIF 的总览为 45 秒；编舞页“基础律动”为六段组成的 30 秒示例。[查看 GIF](../../../../gifs/dance/README.md)。

## 屏幕与实机

这是二维部件动画与三个转向原画的组合，不是完整三维机械臂仿真。时间轴中的角度是屏幕设计参数，底盘角度标签用于选择视图，并非测量得到的机械臂关节角。腕部旋转也是二维示意，尚未实现连续三维透视。不能把这些值或像素坐标直接下发给电机。

实机轨迹还需检查逆解、关节范围、碰撞、速度、加速度和停止过程，再低速调试与动画对齐。当前不发送 CAN 运动命令。

```bash
python3 tools/export_dance_gifs.py
python3 tools/build_screen_preview.py
```

导出仅维护当前十个基本舞蹈与总览，不恢复 `cat-demo` 或“左右交替”。单独保留的 V6 不参与当前固件。GIF 更新后需重新生成资源并编译固件。
