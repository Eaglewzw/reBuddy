# 历史扩展舞蹈原画

本目录保留旧原画和绑定记录，当前舞蹈导出不读取这里的配置。当前十个基本舞蹈使用 [primitives](../primitives/README.md)，旧 GIF 不再恢复。

本组围绕身体节拍设计：底盘转拍、侧摆重拍、上下律动、连环波浪、舒展收拍。每段有回中收尾，供编排重复和组合；不是日常情绪动作的改名。

[body-atlas.png](body-atlas.png) 使用内置 ImageGen（builtin 模式）生成，三个关节的屈伸改变身体姿态；[初始提示词](prompt.txt)、[夹爪与结构修正](correction-prompt.txt)、[方向修正](pose-correction-prompt.txt) 均随工程保存。房间复用现有素材。底盘转向使用[三视角与夹指图层](../../shared/gripper/README.md)。

[rig.json](rig.json) 保存裁剪边界、统一采样比例、落地中心和姿态时间轴。各姿态只按同一个比例采样，然后平移配准到落地中心；不按每帧包围盒重新缩放。图集行间距并不完全相等，因此显式指定实际留白边界，避免裁掉抬起的头部。夹指按固定尺寸绕原安装点旋转。

[poses.png](poses.png) 展示旧动作各三帧，仅作来源留存，不是当前成品。旧动画采用固定 320×240、平均 8 FPS；短动作 2 秒、波浪与收拍 4 秒。关键姿态采用停留与切换，底盘为三个采样方向。源画不同姿态存在手绘轮廓差异，固定采样比例不代表几何精确的机械模型；旧节奏亦未做实机轨迹或电机速度标定。
