# 十个独立基本舞蹈动作原画

每个 `NN-atlas.png` 是 4 列 × 3 行的完整角色姿态图集，以 daily 的 [idle-master.png](../../daily/base/idle-master.png) 为外形参考。由内置 ImageGen 制作；对应 `NN-prompt.txt` 保存提示词，修正版本另有 `NN-repair-prompt.txt`。

按整图的完整角色连通轮廓提取素材，不按格子边界截断头部和夹爪；真正碰到源图片外缘的姿态不进入成片。

少数原画出现反向视角，已通过 `timing.json` 的 `excluded_source_poses` 排除；播放选用同侧完整姿态，没有镜像或拼接修补。这些源格保留用于制作追溯，并非全部进入 GIF。

`timing.json` 定义动作 ID、独立文件名、3／6 秒时长及关键姿态停留。GIF 使用 8 FPS 时间基准，120／130 ms 交替；12 个完整关键姿态包括停留和返回，不能称为 24／48 个独立绘制姿态。导出脚本为 [export_dance_gifs.py](../../../../../tools/export_dance_gifs.py)。本轮不生成组合舞蹈。

每张图集使用统一固定采样比例，以 daily 底盘约 93 像素为基准，完整角色仅平移到落点 (155,190)。无部件裁切重组、变形插帧、透明叠化、播放缩放；不会按每帧身体的包围盒归一化。清理透明背景中的孤立噪点不会更改角色内部结构。首尾复用同一姿态，避免生成原画的首尾差异。

完整角色原画仍可能有局部轮廓差异。自动检查覆盖资源完整性、时序、底盘粗略尺寸、静止背景及循环，不等于严格刚体几何证明。当前是新一轮待视觉确认的动作设计，不是已校准的机械臂轨迹。尤其转向、肩肘连接和夹爪开合，需要逐段观看后再定稿。
