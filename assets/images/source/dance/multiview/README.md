# 二维转身素材

用于当前08稳定摇摆、09横向∞动画。沿用原绿色角色补绘不同观看方向，不使用三维外壳或光照。

- `head_turnaround.png`：内置 **image_gen** 生成并修正眼睛后的九视角透明图集。
- `prompt.txt`：首次补绘的完整提示词。
- `eyes_prompt.txt`：保持布局、修正月牙眼朝向的完整提示词。
- `heads/00.png`～`08.png`：切片并对齐后的绘图。`06.png` 特意用原 `artwork.py` 重绘，作为中性视角，保证待机角色一致。
- `heads.json`：图集、切片校验值与夹爪/腕部绘图锚点。

输入参考为同目录上级的 `approved_character_reference.png`、本机旧GIF九姿态示意图，以及原角色头部绘图。原转身来源和提交记录见 `../github_turn_reference.json`。

`prepare_dance_multiview.py` 只负责图集切片与对齐；`render_dance_multiview.py` 使用对应二维特征点插值，并只显示一份清晰线稿，不交叉淡化两个轮廓。视角索引不是实机头壳角度测量。原动作末端屏幕路径与时间轴保持不变，内部二维连杆重新连接补绘视角的铰链。

身体使用 `tools/dance_body_views.py` 的五组二维绘图关键视角（0/20/40/60/80）：正面显示两侧绿色肩壳、肘部被头部遮挡；侧面展开折线连杆和圆形金属盖。轮廓及锚点使用保形三次插值，保留原画配色和线条，固定底座不参与变形。它不再把完整侧面身体用同一个仿射矩阵压窄。

身体重画保留头部图集、首尾原画和末端轨迹；后续08的连接优化见文末，09保持原版本。生成清单中的 `body_poses` 保存实际二维身体锚点，`poses` 中的旧 `elbow/local_wrist` 只保留作历史运动适配对照。

这些是电脑端制作素材，不自动加入 ESP32 Flash。

08 身体连接修正：撤掉原来单独平移肩部或肘部的补丁。`connected_arm()` 以底盘中心142为固定转轴，两段连杆共用一个随视角变化的二维缩短比例，用原画的固定臂长和同一分支求解肘部位置，终点约束为已确认头部的腕部连接点。肩壳不平移，头部及轨迹不变，09继续使用原来的绘图。全帧检查两段连杆在绘图平面内的长度，防止关节错接或伸缩。这里是二维角色骨架约束，不是实机运动学验证。

08 头身连接过渡：头部图集文件不变；中间帧的二维特征点与腕部锚点统一使用PCHIP插值，经过关键视角时位置和一阶导数连续。腕部盖使用原画的矢量金属关节统一绘制，覆盖图集中不同视角的关节样式；脸部仍只显示一份原画，不交叉淡化。末端屏幕轨迹、头部姿态角和总时长不变，09未改。
