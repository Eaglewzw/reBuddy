# 固件动画资源

当前资源版本为 `gif-v2-rgb565`，包含日常、舞蹈、自动开场收尾。原始 GIF 不修改；日常像素与 120/130 ms 时间轴保留。

- `frames.bin`：去重后的压缩帧；日常为 RGB565，舞蹈为 64 色索引及预计算轮廓覆盖率。
- `room.bin`：原始 320×240 RGB565 房间，舞蹈合成不改变房间颜色。
- `manifest.json`：来源校验、实际取样、帧 CRC/SHA256、压缩格式与限制。
- `main/pet_animation_table.c`：对应帧元数据与片段时间轴，由工具生成。

运行编码 0 为原始回退帧，1 为 zlib RGB565，2 为独立基准 RGB565 XOR，3 为独立色表索引，4 为色表／底色及 zlib 索引和覆盖率平面，5 为较早舞蹈帧的平面 XOR。日常差分不串联；舞蹈最多七层，解码拒绝循环／超深引用。数据编码相对转换结果无损，舞蹈减色和 16 级覆盖率属于有损转换。

多数基础舞蹈以 50 ms 采样，十组基础动作首尾使用同一中立画面。自动段原素材各 3 秒，播放时各占四拍。底盘回转保留稀疏的原始转身姿态，仅增加首尾连接。动画缓存峰值 600 KiB，无运行时洪泛遍历队列。

使用 `python3 tools/build_screen_preview.py` 重新生成。该工具需要 Pillow、NumPy 与 OpenCV；SciPy 可选，只加速背景连通计算。资源已提交，普通固件构建不需要这些图像工具。生成时检查动画 5 MiB 上限，固件构建另检查整体 Flash 预留。

完整格式、取舍和验收边界见 [舞蹈优化说明](../docs/DANCE_OPTIMIZATION.md)。
