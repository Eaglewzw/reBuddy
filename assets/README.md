# 资源目录

| 目录 | 内容 |
| --- | --- |
| [gifs](gifs/README.md) | 当前日常动作、十组舞蹈和独立表情 |
| [images](images/README.md) | 有效原画、角色参考、房间和触摸示意 |
| [docs](docs/GETTING_STARTED.md) | 产品需求、运行说明、编排操作与测试说明 |

图片归入 `images/`，可播放动画归入 `gifs/`；代码位于工程根目录的 `main/`、`components/`、`tools/`、`tests/`。当前只保留使用中的素材及必要制作来源，有效图集和实际导出参数保留在对应源目录。

舞蹈试稿、衍生演示和旧生成脚本已移除。日常动画保留，当前舞蹈统一位于 `gifs/dance/`，采用用户提供合集中的十个原始 GIF。原始产品需求与用户角色参考继续作为设计依据。
